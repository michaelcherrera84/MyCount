Manage Items

Add, edit, or remove inventory items.

How to Manage Items

Loading Items

  1. Click Load Items and select your folder.
    • Note: Depending on your browser, you may not be able to select the folder and may need to select all of the files in the folder instead.
  2. The current items will appear in the form.

Warning! editing or removing items may cause previously saved count sheets that use those items to load incorrectly. Always create a copy of your data files before making changes in this app.

Adding and Removing Items

  • Add: Enter an item name, select a base unit, and select a base storage location. Then click Add Item.
  • Remove: Click Remove Item beside the item you want to remove.

Editing Items

Basic Information

  • You can change the item's name, base unit, or base location at any time.

Additional Units

An item can have multiple units of measurement and be stored in multiple locations. Each additional unit requires a conversion, a unit, and a location.

Adding Additional Units

  1. Click Add Units to add a new unit.
  2. Enter the conversion value and select the unit and location.
  3. Click the button to confirm the unit before adding another.

You must confirm the current unit before you can add another one.

Understanding Unit Conversions

Conversions are based on the item's base unit. The conversion value represents how many of the selected units are equivalent to one base unit.

For example, if the base unit is a case containing two bags of an item, enter "2" as the conversion value and select Bag as the unit.

Storing Units in Multiple Locations

Each additional unit must have a conversion value, unit, and location. You can add the same unit and conversion more than once if the units are stored in different locations.

For example, suppose you store one-third lexans of an item in both the cooler and the makeline. Add two separate entries. Example:

Conversion Unit Location
2 1/3 Lexan Cooler
2 1/3 Lexan Makeline

Both entries would use the same conversion value and unit, but each would have its own location.

Editing and Removing Additional Units

  • Edit: You can change the conversion value, unit, or location of an existing entry.
  • Remove: Click Remove Unit to delete an entry you no longer need.

Saving Your Changes

When you're finished making changes, click Save Items. Your browser will download an updated file named items.json.

Important: Saving does not automatically update the original file! You must replace the existing file with the downloaded version for your changes to take effect the next time you use .

  1. Click Save Items to download the updated file.
  2. Locate the downloaded items.json file. Depending on your browser settings, it may automatically save to your default Downloads folder without prompting you to choose a location.
  3. Open the downloaded file's location and copy or move it into your folder.
  4. Replace the existing items.json file when prompted. Make sure the new file has the same name and is in the correct folder.

Once you've replaced the original file, your changes are saved and will be available the next time you load the items.

Tip: If you're unsure whether your changes were saved correctly, reopen the updated items.json file in your editor and verify its contents.
