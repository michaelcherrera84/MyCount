How to Manage Units

Loading Units

  1. Click Load Units and select your existing units.json file from your folder.
  2. The current units will appear in the form.

Warning! editing or removing units may cause previously saved count sheets that use those units to load incorrectly and may affect items that use those units. Always create a copy of your data files before making changes in this app. If you remove units that are used by any items, remember to modify those items to correct the missing locations.

Adding, Editing, and Removing Units

  • Add: Enter a unit name and abbreviation in the new unit fields and click Add Unit.
  • Edit: Change the name and/or abbreviation in the corresponding text field.
  • Remove: Click Remove beside the unit you want to remove.

Saving Your Changes

When you're finished making changes, click Save Units. Your browser will download an updated file named units.json.

Important: Saving does not automatically update the original file! You must replace the existing file with the downloaded version for your changes to take effect the next time you use Countulator.

  1. Click Save Units to download the updated file.
  2. Locate the downloaded units.json file. Depending on your browser settings, it may automatically save to your default Downloads folder without prompting you to choose a location.
  3. Open the downloaded file's location and copy or move it into your folder.
  4. Replace the existing units.json file when prompted. Make sure the new file has the same name and is in the correct folder.

Once you've replaced the original file, your changes are saved and will be available the next time you load the units.

Tip: If you're unsure whether your changes were saved correctly, reopen the updated units.json file in your editor and verify its contents.
