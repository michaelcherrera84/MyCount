How to Manage Locations

Loading Locations

  1. Click Load Locations and select your existing locations.json file from your folder.
  2. The current locations will appear in the form.

Warning! editing or removing locations may cause previously saved count sheets that use those locations to load incorrectly and may affect items that use those locations. Always create a copy of your data files before making changes in this app. If you remove locations that are used by any items, remember to modify those items to correct the missing locations.

Adding, Editing, and Removing Locations

  • Add: Enter a location name in the new location field and click Add Location.
  • Edit: Change the name in the corresponding text field.
  • Remove: Click Remove beside the location you want to remove.

Saving Your Changes

When you're finished making changes, click Save Locations. Your browser will download an updated file named locations.json.

Important: Saving does not automatically update the original file! You must replace the existing file with the downloaded version for your changes to take effect the next time you use .

  1. Click Save Locations to download the updated file.
  2. Locate the downloaded locations.json file. Depending on your browser settings, it may automatically save to your default Downloads folder without prompting you to choose a location.
  3. Open the downloaded file's location and copy or move it into your folder.
  4. Replace the existing locations.json file when prompted. Make sure the new file has the same name and is in the correct folder.

Once you've replaced the original file, your changes are saved and will be available the next time you load the locations.

Tip: If you're unsure whether your changes were saved correctly, reopen the updated locations.json file in your editor and verify its contents.
